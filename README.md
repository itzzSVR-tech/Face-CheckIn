# **App Name**: FaceCheck In

## Core Features:

- Webcam Integration: Capture live video stream from the user's webcam.
- Facial Recognition: Use facial recognition to identify individuals from the video stream.
- Attendance Marking: Mark attendance based on successful facial recognition. The tool will use a confidence threshold.
- Live View Display: Display a real-time view of the webcam feed with face detection overlays.
- Attendance Reporting: Show attendance records and summaries.

## Style Guidelines:

- Primary color: Dark blue (#0E2A47) for a professional feel.
- Secondary color: Light gray (#F0F0F0) for backgrounds and content areas.
- Accent: Teal (#20c997) for interactive elements and highlights.
- Clean and modern layout with clear visual hierarchy.
- Simple and easily recognizable icons for navigation and actions.
- Subtle transitions and animations to provide feedback and enhance user experience.

## Original User Request:
Smart Attendance System with facial recognition. Live webcam integration wih Python OpenCV
